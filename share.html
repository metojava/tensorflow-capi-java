tensorflow-capi-java — Setup Guide

A self-contained Java deep-learning library built directly on the TensorFlow C API via JNI: Keras-style fit(), a composable Sequential layer API (Dense, Conv2D, MaxPool2D, Flatten, ReLU, Input) and pluggable optimizers (SGD, Momentum, Adam).

What is in the repo vs. what you must download

PathIn repo?Why
src/ (Java + JNI C sources)YESthe actual library
pom.xml, README.md, tutorial.htmlYESbuild & docs
target/noMaven build output — regenerated locally by mvn
native/dist/noTensorFlow C API binaries (~900 MB) — too large for GitHub's 100 MB file limit; download once (below)

Step 1 — Prerequisites

  • JDK 17+ (JAVA_HOME must be set)
  • Maven
  • Windows: MSYS2 with gcc (pacman -S mingw-w64-ucrt-x86_64-gcc)
  • Linux/macOS: any gcc/clang — adjust build-native.sh paths if needed

Step 2 — Download the TensorFlow C API (~900 MB)

Grab the CPU package for your platform from the official TensorFlow C API install page (direct assets live on the tensorflow releases page, e.g. libtensorflow-cpu-windows-x86_64-2.16.1.zip).

Extract it so the project has this layout:

tensorflow-capi-java/
└── native/
    └── dist/
        ├── include/          ← from the zip
        └── lib/
            └── tensorflow.dll  ← from the zip
Note: the folder is named native/dist by convention here — any path works, because you pass it to the build script as an argument in the next step.

Step 3 — Build the JNI bridge

From the project root (Windows / MSYS2):

& "C:\msys64\usr\bin\bash.exe" src/main/native/build-native.sh `
    "C:\...\tensorflow-capi-java\native\dist"

The script compiles tf_capi_jni.c + tf_graph_jni.c into target/native/tf_capi_jni.dll.

Step 4 — Put the DLLs where the loader finds them

# JNI bridge
Copy-Item target\native\tf_capi_jni.dll target\classes\native\windows-x86_64\ -Force

# TensorFlow itself (loader resolves it from java.library.path or PATH)
Copy-Item native\dist\lib\tensorflow.dll target\classes\ -Force

Alternatively add native\dist\lib to PATH, or set -Djava.library.path. The library searches, in order:

  1. TF_CAPI_NATIVE_DIR environment variable
  2. classpath /native/<os>-<arch>/
  3. standard system library paths

Step 5 — Build & run

mvn compile
# train a CNN on Fashion-MNIST end-to-end:
mvn compile exec:java -Dexec.mainClass=com.example.tfcapi.demo.FashionMnistDemo
